# 星桥项目 · 示例知识手册

## 项目定位
星桥是一个虚构的单机任务管理项目。本资料仅用于体验 TraceBase，不代表任何真实业务系统。

## 本地运行与环境变量
使用 Node.js 22，执行 npm ci 安装依赖，执行 npm run dev 启动开发服务。
PORT 是本地服务端口，默认值 3400。DATA_DIR 是本地数据目录，默认值 .data。
DEEPSEEK_API_KEY 是可选配置，只用于生成任务摘要。不配置时仍可创建和查询任务。
不要把 .env 文件提交到 Git。修改环境变量后需要重启服务。

## 部署约束
当前版本仅供本机使用，没有用户认证，不应直接暴露公网。生产部署前必须增加登录鉴权与备份机制。

## 为什么没有 Redis
设计记录 2026-09-01：项目只有单机使用场景，并发需求较低，所以第一版采用数据库中的任务表，不引入 Redis 队列，以减少部署和维护成本。
这只适用于当前单机版本，不代表多实例部署也无需共享队列。

## 端口占用排查
如果启动提示 EADDRINUSE，先检查是否已经有旧服务运行。可以停止旧服务，或修改 PORT 后重启。不要直接结束不属于本项目的进程。
