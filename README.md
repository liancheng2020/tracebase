# TraceBase

> 项目知识，有据可循。

面向个人开发者与小型开发团队的本机知识库：导入项目资料，围绕证据提问，让答案与原文一起呈现。

## 第一版

- 知识空间隔离，导入 Markdown、UTF-8 TXT / HTML（含 .htm）、文字型 PDF。
- 后台索引、错误提示、文件更新、版本记录与删除同步。
- 关键词 + 向量混合检索，点击引用在右侧定位原文。
- DeepSeek 通俗回答；无 Key 或校验失败时仅展示原文摘录，找不到资料时明确拒答。
- 最近问答、检索记录、准确性反馈及知识健康面板。

## 启动

Node.js **22.13+**，Windows / macOS / Linux：

```sh
npm ci
npm run dev
```

访问 http://localhost:3200 。创建空间后可点击“从示例开始”。示例为明确标注的虚构项目，不自动导入用户资料。

无需 Docker 或单独安装数据库。使用 PGlite（嵌入式 PostgreSQL）+ pgvector，数据保存在 .data；同一数据目录仅运行一个服务。停止服务后可备份整个目录。

## 模型配置

把 .env.example 复制为 .env，按需配置并重启：

| 变量                                                     | 用途                                                  |
| -------------------------------------------------------- | ----------------------------------------------------- |
| DEEPSEEK_API_KEY                                         | 可选，启用生成式回答；默认 deepseek-chat              |
| EMBEDDING_BASE_URL / EMBEDDING_API_KEY / EMBEDDING_MODEL | 独立、兼容 /embeddings 的服务，三项齐备才启用向量检索 |
| PORT / DATA_DIR                                          | 默认 3200 / .data                                     |

DeepSeek 聊天接口不能冒充 embedding 接口。未配置向量时明确使用关键词检索；配置或更换向量模型后，对已有文档执行“重试索引”。旧模型向量不会与新模型混用。

配置外部模型意味着文档片段和问题会发送到该服务。不要导入不允许外发的资料，不要提交 .env。

## 开发与验证

```sh
npm run build
npm start
npm test
npm run test:ui
```

UI 测试使用真实内存数据库及本机 Edge，不读取个人资料或调用付费模型；需预装 Edge，或用 BROWSER_CHANNEL 指定已安装的 Chrome。截图保存在 artifacts/。

## 边界

这是**无登录的本机单进程版**，不是企业多租户服务。空间隔离不等于用户权限；勿直接暴露公网。

单文件 8MB，最多100页 PDF / 15万文本字符 / 300个片段，每空间100份文档。不支持扫描件 OCR、GitHub 自动同步、自动冲突判定和网页抓取。

引用校验只证明引用存在且摘录准确，不证明模型推理一定正确。检索阈值尚需真实语料评估。回答流先发送处理进度，全文校验后再按段发送，不展示未经验证的模型 token。

### HTML 原型导入

支持上传单个 UTF-8 编码的 .html / .htm 文件，提取页面标题、章节、正文、表格、按钮及表单提示。与其他资料一样可更新、索引和引用，原文侧栏展示提取后的文字，不执行或渲染原型代码。

不加载外部图片、样式、脚本或 iframe。主要内容由 JavaScript 生成的原型（例如部分 Axure 导出）请先导出含正文的静态 HTML、文字型 PDF 或需求文档；不支持 ZIP 原型包、交互复现或截图理解。单文件仍为 8MB，提取正文最多15万字符。
